شعار MODYX AI الرسمي — دقة عالية
================================
1. ضع ملف الشعار هنا بهذا الاسم بالضبط:  logo.png
2. استخدم أعلى دقة متوفرة (يفضل 1024×1024 أو أعلى، خلفية داكنة/شفافة PNG).
3. لا تضغط الملف — التطبيق يعرضه كما هو بجودته الكاملة.
4. سيظهر تلقائيًا في: شاشة البداية، الترويسة، الدرج، الصفحة التعريفية،
   أيقونة المتصفح (favicon)، أيقونة الهاتف، وتطبيق PWA.
5. بدون الملف يعمل التطبيق بالهوية النصية الحالية (لا شيء ينكسر).
